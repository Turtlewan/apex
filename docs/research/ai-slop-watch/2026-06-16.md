# AI-Slop Watch — Visual / UI / Product DESIGN tells

_Research date: 2026-06-16. Scope: design-level tells (composition, layout, structure, typography treatment, imagery, iconography, spacing, visual clichés). **Color/palette findings excluded** except where structural._

The single most useful primary source this cycle is **Adrian Krebs' "Scoring Show HN submissions for AI design patterns"** (Apr 2026): he ran 1,590 Show HN landing pages through Playwright and scored each against 16 DOM/CSS "tells." 22% heavy slop, 32% mild, 46% clean. The recurring theme across all sources: the problem is **unconsidered defaults**, not the patterns themselves — but the patterns are now reliable AI fingerprints.

---

## Established design-slop tells

- **Centered hero: pill/capsule badge → oversized H1 → vague subtext → two buttons.** Canonical AI hero stack; capsule badge above title ~4.7%, centered-hero composite is the headline tell. (Krebs; Taste Skill; Developers Digest)
- **Oversized headline + vague copy.** Huge display headline + generic subtext ("the visual equivalent of 'in today's fast-paced world'"). Taste Skill caps headlines 2 lines, subtext 20 words. (Taste Skill; Developers Digest)
- **Three feature cards in a row / icon-topped feature-card grid.** Icon-card grids on 22% of pages. "Small rounded-square icon container above a heading" = "the universal AI feature-card template." (Krebs; Developers Digest)
- **Uniform border radius everywhere + over-rounding.** Same radius on every card/section/input; over-rounding (24px+ small card) "rounds everything into the same soft blob"; cards should top out ~12–16px. (Krebs; Developers Digest)
- **Colored left-border on cards.** "Almost as reliable a sign of AI-generated design as em-dashes for text." (Krebs / GIGAZINE)
- **Identical/symmetric stacked sections.** Full-width sections stacked vertically, each centered title + symmetric grid; no rhythm/hierarchy. (Developers Digest; The Crit)
- **Bento grid used reflexively.** Deployed as a default "look modern" move rather than to serve content. (Creative Boom; Sayenko; trend pieces)
- **Glassmorphism / frosted-glass cards.** Dominant CSS fingerprint, "LLM default since 2022." Structural when it's the frosted card treatment. (925studios; GIGAZINE)
- **Numbered step sequences + stat banners.** "1-2-3" how-it-works rows and big-number stat strips as canned sections. (Krebs)
- **Emoji used as interface/feature icons.** "Sidebar with emoji icons" among Krebs' 16. (Krebs)
- **All-caps eyebrow / section labels.** Tiny all-caps kicker above every heading. (Krebs)
- **Default stroke icon sets used verbatim (Lucide / Heroicons).** "Heroicons heavily used in AI-generated UI, feels familiar rather than distinctive." (Anti-Slop Framework; Fountain Institute; hugeicons)
- **Inter / system font everywhere.** Most common font tell; flat, no type personality. (Krebs; Taste Skill)
- **Hand-coded SVG mascot/scene illustrations.** "Read as amateur doodles, not whimsy." (Developers Digest)
- **Centered cards with excessive padding + no visual hierarchy.** "No hierarchy, no breathing room." (Fountain Institute, "7 Signs a UI Has Been Vibe Coded")

## Newly-trending (2026)

- **Fake dashboard mockups + floating icon "pills."** Anti-Slop Framework (Elkholy, May 2026) and frontend-design skills now call out "fake product mockups," "fake dashboard mockups," "floating icon pills." (Elkholy, May 2026)
- **Over-smooth AI hero imagery / glossy 3D blobs.** Hero images "overly smooth, overly sharp, unnatural"; metallic chrome "blob" renders floating in space. (Travis Nicholson, Apr 2026; reallygooddesigns 2026)
- **"Spacing over cards" as the corrective.** Wrapping everything in cards (cards nesting cards) is now the tell; Impeccable bans "cards wrapping everything." (Anti-Slop Framework; Impeccable, Bakaus 2026)
- **Anti-design / naïve-design backlash as counter-aesthetic.** 2026's dominant reaction: asymmetry, visible grids, rough texture, awkward proportions, wobbly linework. Over-symmetry/uniform spacing now reads as the slop signal. (Creative Boom; Lindsay Marsh; designmagazine.com.au; aigoodies)
- **"Impeccable" / Taste Skill negative-constraint movement.** Open-source anti-slop skills (Impeccable 10k+ stars; Taste Skill; UI/UX Pro Max) codify what NOT to do: ban em-dashes, in-hero badges unless real launch, single-line ≤80px nav. (Impeccable; Taste Skill; emelia.io)
- **Permanent dark theme with low-contrast body text.** Krebs' single most common tell (34%); flagged as both fingerprint and accessibility failure. (Krebs / GIGAZINE)
