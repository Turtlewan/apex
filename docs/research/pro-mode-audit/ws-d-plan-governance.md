## Calibration premise (read before the table)

Pro mode targets **DeepSeek V4 Pro**. The benchmark workstream establishes that V4 Pro is **stronger than Flash but still measurably below Opus 4.8** on every *independently-verified* coding/agentic/reasoning benchmark (SWE-bench Verified Opus +8pp, Terminal-Bench Opus +6.7pp, agentic composite Opus +6.1, HLE Opus +20pp). The coding composite is near-tied (+0.5), but agentic + reasoning gaps are real. **V4 Pro is a competent coder, not a frontier reasoner.**

The weak-coder evidence shows two decay shapes: **exponential** decay from the first few rules (small/weak models, Flash-class) vs **threshold** decay (frontier — graceful until ~150 rules). V4 Pro sits *between* these — most likely a **linear** profile (the evidence's middle tier, e.g. GPT-4.1 / Claude Sonnet class). That means:
- Pro raises the floor where Flash hits zero (the `arXiv:2605.06445` near-zero-at-L3 floor, the exponential `2507.11538` floor) — so **spec-literalness compensations that exist purely because Flash *cannot* recover from ambiguity/exploration can loosen conservatively.**
- Pro does **not** earn frontier-tier trust. It still shows linear constraint decay, still treats tokens equally in self-attention (the `2502.15851` architectural root cause is model-family-agnostic), and is the *weaker* family relative to Claude. So **review-redundancy that guards against decay loosens only partially, and Pro never becomes the strong reviewer.**
- **All safety/governance/authority gates are KEEP regardless of model strength** — they encode *who may authorise an action*, not *how capable the coder is*. No capability uplift touches them.

Relaxations below are inferred from benchmarks, not observed. Default is KEEP. Every relaxed item carries a conservative form.

## Notes on deliberate KEEPs (safety / authority — not relaxable)

Per the WS-D principle, every **authority gate and hard block was kept regardless of V4 Pro's strength**, because they encode *who may authorise an action*, not *how good the coder is*:
- Hard blocks (#15), critical-file confirmation (#16), permissions pre-authorisation (#17), autonomy levels + approval gates (#14), no-retry-on-denied (#13), evaluator independence (#19).
- The design-brief/doc-coverage compensation (#20) was kept because it targets a **modality gap (no vision)** that V4 Pro shares — not a reasoning-capability gap that Pro closes.
- The dispatched domain review (#10) was kept because it runs in **planning mode (Claude)** against the *spec*, so the coding model's strength is irrelevant to it.

## The relax candidates are spec-literalness + review-redundancy only

Consistent with the brief, the four RELAX items are all **spec-literalness** (#1 bounded exploration, #4 split threshold, #9 wave-plan delegation) or **review-redundancy** (#12 santa dual-pass), and the single PRO-UNLOCK (#11) is a **role clarification** that keeps Claude as the strong cross-model reviewer. No safety, authority, or hard-block row was relaxed. All relaxations are conservative (escape-hatches and threshold bumps, not removals) because V4 Pro is a *linear-decay middle-tier* coder — above Flash's exponential floor, below Claude's frontier threshold.
