## Gotchas found

  with a byte-safe bash `git diff | git apply` (plus a hash-object check before and after). Piping
  patches through PowerShell strings re-encodes non-ASCII and breaks the apply.
- The family gate binds a review to the task worktree's end-state digest, and a task-branch commit
  changes that digest. Review BEFORE any task-branch commit, or restore with

  Engine stage should bind reviews correctly by construction.
