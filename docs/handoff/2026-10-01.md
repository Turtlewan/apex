## Gotchas found

- The destructive-command guard hook blocks `git checkout <branch> -- <files>`. Integrate instead
  with a byte-safe bash `git diff | git apply` (plus a hash-object check before and after). Piping
  patches through PowerShell strings re-encodes non-ASCII and breaks the apply.
- The family gate binds a review to the task worktree's end-state digest, and a task-branch commit
  changes that digest. Review BEFORE any task-branch commit, or restore with
  `git reset --mixed HEAD~1` (proven to restore the exact digest). The future build-orchestrator
  Engine stage should bind reviews correctly by construction.
- A tree pin in `~/.claude` was voided by harness skill-sync churn — the reason spec 1 exists.
- The eight-minute no-output watchdog (exit 124) fires during long silent generations. A coder may
  still be running underneath it; check the process ID before acting on the timeout.
- Running a child PowerShell process from a PowerShell background task returned -196608 for
  everything (launch failure); run suites from bash instead.
- A transient `codex/stage1-base` branch carried integrated work as each wave's base (build
  mechanics, not a decision).
- The pre-build `--ignored` scope snapshot was NOT saved for either spec (host miss). Both scope
  criteria (acceptance criterion 8, and the scope `Compare-Object`) go to the owner with substitute
