  *new* file there invisible to it, so a review pin over a newly created file in `~/.claude` protects
  nothing. Hash the file directly as a content pin instead (done this session for wave-3 and the
  post-build gates).

  skill cap, or the estimate reads ~20% low.

  inside an otherwise-legitimate probe command — write probes without inline cleanup.
