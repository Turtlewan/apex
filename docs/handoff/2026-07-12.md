2. Found + fixed a real bug during that extension: `Test-AfkArmed`'s date parsing combined `DateTimeStyles.RoundtripKind` with `AdjustToUniversal`, which .NET throws on — silently caught, making the armed-check always return false. Root-caused via an isolated PowerShell snippet outside any file I/O; fixed by swapping to `AdjustToUniversal -bor AssumeUniversal`.

3. Honored the spec's own `cross_model_review: true` flag after the green integration matrix: dispatched an independent Opus review, which found 3 real BLOCK-level security gaps the integration tests could not have caught (every integration probe targeted a command class the detectors were explicitly built to catch; none exercised the gap classes found): (a) the "safe" Bash allowlist included general-purpose interpreters/package managers (`node -e`, `python -c`, `npx`, `npm install`, `find -exec`, `awk system`, `git -c core.fsmonitor=`) reachable for RCE/dependency-poisoning outside the never-list detectors' coverage; (b) the arm-write guard only recognized the `~/.claude/afk.on` form, not the actual absolute path the hook itself uses, so an armed session could silently rewrite its own expiry; (c) the guard's own `settings.json`/hook files weren't on the critical-path exclusion list, so an armed session could disable the entire guard via an ordinary file write. All 3 fixed same session (narrowed `SAFE_AFK_COMMANDS` with targeted argument-level guards for `find`/`git` rather than removing them wholesale; unified critical-path logic into the shared detection module with self-config protection, extended to Bash-based file-copy commands too; fixed the absolute-path detection gap). Verified via 30 isolated unit checks plus a final 7-case live-armed re-verification — all green, zero regressions.

4. **Mark review needed ⚠️:** the live `afk`/`afk off` PowerShell launcher was verified only by static code read, not live execution — the agent is structurally blocked from self-testing it (the harness's own permission classifier correctly refuses to let the agent arm its own AFK bypass, even for testing purposes).
