# Spec: Engine core
<!-- Governing contract: references/spec-contract.md. -->

**Identity:** Add a single-repo, single-spec Engine for low/medium-risk execution-manifest builds, with durable resume and proof-gated teardown.
<!-- Decision record: docs/technical/adr/ADR-048-role-redesign.md. -->

## Intent
- **Intent:** Run manifest tasks through the existing Codex wrapper, integrate verified waves, and hand the completed build to the host for close-out.
- **Invariants:** Task trees retain their build-end HEAD and files until teardown; only the integration branch receives wave commits; main receives verified per-file hand-off without a commit. Every transition is durable and resumable. Hand-off is per-file verified, journaled, stop-on-first-mismatch; it is not atomic against concurrent writers.
- **Non-goals:** High-risk execution, multi-repo builds, pause-after-wave review, queue/watcher, quota wait-and-resume, default route cutover, automatic success-cleanup/archival, skill-prose changes, or host close-out automation.
